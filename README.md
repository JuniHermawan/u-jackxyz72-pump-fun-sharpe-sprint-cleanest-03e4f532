A steady two-tier paper-trading bot for a 6-hour pump.fun replay, ranked by hourly Sharpe ratio. The strict tier buys only coins with proven real demand (age, real SOL, distinct buyers, net inflow, no whale, pullback to 75% of high, creator never sold) and exits mechanically (stop -20%, take-profit +100%, trailing 35%). A rate-limited micro-scout tier (0.0105 SOL, fast exits) lifts the distinct-mint count over the 20-mint guardrail in a short 6-hour final window at minimal Sharpe cost. Deterministic: no clock, no randomness, no network.
